# yt2009 ai usage policy

yt2009 in itself does not use artificial intellingence tools for development,
however due to the open-source nature of the project, ai-assisted issues
and pull requests have come in the past. the goal of this file is to clarify
usage of such tools in a few points.

- **any** ai assistance must be disclosed, even if only used  to write
a description of your issue/changes.
- **small** changes assisted by coding tools are allowed if following the code
style (see `contributing.md`), is of same quality as all other code
in this repo, and the usage is properly disclosed as mentioned above.
- any code submitted as a pull request must be carefully reviewed by
a human beforehand. a human shall be able to answer any questions relating
to code changes they are about to push. commits shall also be made
and pushed by a human.
- fully-automated/agentic workflows are strictly disallowed.
- human-made descriptions/code changes are still much prefered and usage
of ai tools may negatively impact your response times.
